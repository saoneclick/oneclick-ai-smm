# Идеи и правила

Журнал. Пополняется по ходу работы. Формат: `YYYY-MM-DD — идея/правило`.

## Идеи

- 2026-09-16 — AI-маркетолог должен присылать посты на согласование **после каждого IT-свершения** Ивана.
- 2026-09-16 — Собирать обратную связь (переделать/отмена) и учиться на ней.
- 2026-09-16 — Система должна вести себя «как живой человек» (голос Ивана, вариативность, ритм).
- 2026-09-16 — Продумать передачу информации между проектами и сессиями (несколько AI-агентов, обмен заданиями).
- 2026-09-16 — Возможные источники свершений: Битрикс24 (закрытые задачи/проекты), ручная команда `/done`.
- 2026-09-16 — Плейлисты каналов: один пост → разная упаковка под Telegram / VK / MAX / Дзен / TenChat / LinkedIn.

## Правила

- 2026-09-16 — Секреты храним только в `infra/*.local.env`; в git не коммитим.
- 2026-09-16 — Черновики и вся память — в PostgreSQL (единый источник правды).
- 2026-09-16 — Каждое действие по посту (одобрено/отложено/переделано/отменено) пишем в таблицу `feedback`.
- 2026-09-16 — Правила стиля храним в `style_rules` и подставляем в каждый промпт генерации.
- 2026-09-16 — Любая новая идея/правило фиксируется в этом файле.
- 2026-09-16 — Перед публикацией пост согласовывается Иваном (кроме случаев, когда он явно разрешил автопубликацию).
- 2026-09-16 — НЕ редактировать файлы с кириллицей через PowerShell `Get-Content`/`Set-Content` — ломает UTF-8 (двойное кодирование). Только через инструмент Edit или Python.
