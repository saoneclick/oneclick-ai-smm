# Промпты и редакционная логика

Промпты живут в `services/ai_smm/prompts.py`. Они разделены на два шага, чтобы
модель сначала думала стратегически, а потом писала — это заметно снижает
«AI-воду» и повторы.

## Шаг 1. Strategist

Вход:

- бриф из интервью;
- активные правила стиля из `style_rules`;
- 3 последних опубликованных поста как ориентир голоса (не для копирования).

Выход:

```json
{
  "goal": "...",
  "audience": "...",
  "insight": "...",
  "angle": "...",
  "hook_options": ["...", "...", "..."],
  "recommended_hook": "...",
  "structure": ["..."],
  "key_message": "...",
  "proof_points": ["..."],
  "objections": ["..."],
  "cta": "...",
  "visual_direction": "...",
  "risks": ["..."]
}
```

Принципы:

- один пост = одна мысль и один CTA;
- сначала напряжение/инсайт, потом решение;
- конкретика вместо общих слов;
- не выдумывать цифры, кейсы и отзывы;
- учитывать возражения аудитории;
- заголовок карточки 3–7 слов и понятен без текста поста.

## Шаг 2. Copywriter + self-critique

Вход:

- бриф;
- стратегия;
- правила стиля;
- примеры;
- наличие картинок;
- список каналов.

Модель обязана:

1. придумать 5 хуков и выбрать лучший;
2. написать версии под TG / VK / MAX;
3. написать Дзен-статью;
4. предложить обложку: `art`, `theme`, `layout`;
5. оценить себя по 10 критериям;
6. переписать всё, что ниже 8/10;
7. вернуть строгий JSON.

## Рубрика

| Критерий | Что проверяем |
|---|---|
| hook | цепляет ли первая строка без картинки |
| clarity | понятна ли мысль с первого чтения |
| specificity | есть ли детали, цифры, роли, сроки |
| proof | есть ли доказательства; нет данных — нет выдумок |
| emotion | узнавание, напряжение, эмоция |
| cta | совпадает с целью и уместен |
| platform_fit | длина и формат площадки |
| anti_cliche | нет штампов и канцелярита |
| shareability | захочется переслать/сохранить |
| visual_fit | можно ли собрать сильную карточку |

Средняя оценка пишется в `content_drafts.quality_score`.

## Anti-cliché

Запрещены:

- «в современном мире», «не секрет, что», «динамично развивающийся»;
- «инновационные решения», «комплексный подход», «синергия»;
- «широкий спектр услуг», «гибкие условия», «индивидуальный подход»;
- пустые обещания роста без доказательств;
- канцелярит и пассивный залог;
- CAPS LOCK, три восклицательных знака, эмодзи-салют;
- выдуманные цифры и отзывы.

## Форматы

- **Кейс** — проблема → решение → результат в цифрах → выгода.
- **Разбор** — наблюдение → причины → что делать.
- **Чек-лист** — 3–5 практичных пунктов с объяснением.
- **История** — сцена, конфликт, поворот, вывод.
- **Провокация** — спорная мысль, аргументы, приглашение к обсуждению.

## Почему два шага

Один промпт «напиши вирусный пост» обычно даёт кликбейт и общие слова. Два шага
разделяют ответственность:

- стратег отвечает за смысл и угол;
- копирайтер — за язык и площадку;
- self-critique — за качество до публикации.

Это ближе к работе редакции: бриф → стратегия → текст → редактура → факт-чек →
визуал → согласование.
