# Шрифты

| Файл | Шрифт | Лицензия |
|---|---|---|
| `Inter-var-*.woff2` | [Inter](https://github.com/rsms/inter) | SIL Open Font License 1.1 — `OFL-Inter.txt` |
| `Unbounded-var-*.woff2` | [Unbounded](https://github.com/googlefonts/Unbounded) | SIL Open Font License 1.1 — `OFL-Unbounded.txt` |

Это сабсеты Google Fonts (кириллица + латиница), скачанные как woff2. Они
встраиваются в HTML при рендере, поэтому сервису не нужны системные шрифты и
доступ к сети.
